Demo product

A product page with ONE extension slot. The page knows nothing about personalization: a generic bridge (extension-bridge.js) listens for zb:event, keeps Add to cart disabled while the extension says so, and on click asks the extension to prepare, then puts the returned values on the cart line.

The element decides for itself whether this product can be personalized: it renders a trigger button only when the product has a published template (try ?product=plain-product, which has none, and the slot stays empty). The button opens the editor in a modal; Save customization stores the design and closes it; Add to cart then reuses that design. The page only supplies the product context and the button style (right).
