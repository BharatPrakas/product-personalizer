Plain HTML host: store admin

No Angular here: this page loads one module (../store-admin.js), assigns properties and listens to events. Templates are stored in this browser (IndexedDB) because no api-base-url is set. Create a template, publish it, then open Product mapping and map it to one of the fake products below; the storefront page resolves products the same way.

The product list is a fake catalog the host passes in as productCatalog; the element never invents products.
